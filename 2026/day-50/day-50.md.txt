# What is Kubernetes?

Kubernetes (K8s) is an open-source container orchestration platform that automates the deployment, scaling, networking, and management of containerized applications.

It was originally developed by Google based on its internal Borg system and is now maintained by the Cloud Native Computing Foundation (CNCF).

---

# Why Kubernetes?

Docker helps run a single container or a few containers.

Kubernetes helps manage hundreds or thousands of containers across multiple servers by providing:

* Container orchestration
* Auto scaling
* Self-healing
* Service discovery
* Load balancing
* Rolling updates and rollbacks
* High availability

---

# Kubernetes Architecture

## Control Plane Components

### API Server

Acts as the entry point for all cluster requests. Every `kubectl` command communicates with the API Server.

### etcd

A distributed key-value database that stores the entire cluster state and configuration.

### Scheduler

Assigns newly created Pods to the most suitable Worker Node.

### Controller Manager

Continuously monitors the cluster and ensures that the current state matches the desired state.

---

## Worker Node Components

### kubelet

Runs on every worker node and communicates with the API Server to manage Pods.

### kube-proxy

Handles networking, service discovery, and communication between Pods.

### Container Runtime

Responsible for running containers.

Examples:

* containerd
* CRI-O

---

# Request Flow

```text id="ljlwmg"
kubectl apply
      │
      ▼
API Server
      │
      ▼
etcd stores configuration
      │
      ▼
Scheduler selects Worker Node
      │
      ▼
kubelet creates Pod
      │
      ▼
Container Runtime starts Container
      │
      ▼
kube-proxy enables networking
```

# kubectl Commands Practiced

```bash
kubectl version --client
kubectl cluster-info

kubectl describe node <node-name>
kubectl get namespaces
kubectl get pods -A
kubectl get pods -n kube-system
kubectl config current-context
kubectl config get-contexts
kubectl config view
```

# Cluster Lifecycle

Created Cluster

```bash
kind create cluster --name devops-cluster
```

Deleted Cluster

```bash
kind delete cluster --name devops-cluster
```

Verified Cluster

```bash
kubectl get nodes
```
