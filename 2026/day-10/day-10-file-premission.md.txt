# Understanding Permissions

Permission Format:

```text
rwxrwxrwx
```

- r = read (4)
- w = write (2)
- x = execute (1)

Checked permissions using:

```bash
ls -l devops.txt notes.txt script.sh
```

Observed:
- Owner had read/write access
- Group and others had limited permissions
- `script.sh` was not executable initially

---

# Modify Permissions

## Make script.sh Executable

```bash
chmod +x script.sh
```

Run script:

```bash
./script.sh
```

---

## Make devops.txt Read-Only

```bash
chmod a-w devops.txt
```

---

## Set notes.txt Permission to 640

```bash
chmod 640 notes.txt
```

---

## Create Directory with 755 Permission

```bash
mkdir project
chmod 755 project
```

---

# Verify Updated Permissions

```bash
ls -l
```

---

# Test Permissions

## Try Writing to Read-Only File

```bash
echo "test" >> devops.txt
```

Observed:
- Permission denied error occurred.

---

## Try Executing File Without Execute Permission

```bash
./notes.txt
```

Observed:
- Permission denied because execute permission was missing.
