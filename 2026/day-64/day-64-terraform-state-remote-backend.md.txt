# 🚀 TerraWeek Challenge – Day 64 | Terraform State Management & Remote Backends

## 📖 Overview

On Day 64, I learned how Terraform manages infrastructure using its **State File** and why it is considered the backbone of Infrastructure as Code.

I migrated my local state to an **Amazon S3 Remote Backend**, configured **DynamoDB State Locking**, imported existing AWS resources into Terraform, performed state operations, and explored how Terraform detects and resolves infrastructure drift.

---

## 🎯 Objectives

* Understand Terraform State
* Inspect State File
* Configure Remote Backend
* Enable State Locking
* Import Existing Resources
* Perform State Operations
* Detect & Resolve State Drift

## 🎯 Key Learnings

* Terraform State is the source of truth.
* Remote Backends improve collaboration.
* DynamoDB prevents concurrent state modifications.
* Existing infrastructure can be imported without recreation.
* Terraform detects infrastructure drift automatically.
* Proper state management is critical for production environments.
