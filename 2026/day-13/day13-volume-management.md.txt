# Day 13 – Linux Volume Management (LVM) 🚀

# Commands Used

## Switch to Root User

```bash
sudo -i
```

---

# Task 1: Check Current Storage

```bash
lsblk
```

```bash
pvs
```

```bash
vgs
```

```bash
lvs
```

```bash
df -h
```

Observed:
- Checked available disks and mounted file systems
- No existing physical volumes or logical volumes found initially

---

# Create Virtual Disk

```bash
dd if=/dev/zero of=/tmp/disk1.img bs=1M count=1024
```

```bash
losetup -fP /tmp/disk1.img
```

```bash
losetup -a
```

Observed:
- Created a 1GB virtual disk image
- Attached loop device successfully

---

# Task 2: Create Physical Volume

```bash
pvcreate /dev/loop0
```

```bash
pvs
```

Observed:
- Physical volume created successfully

---

# Task 3: Create Volume Group

```bash
vgcreate devops-vg /dev/loop0
```

```bash
vgs
```

Observed:
- Volume group `devops-vg` created successfully

---

# Task 4: Create Logical Volume

```bash
lvcreate -L 500M -n app-data devops-vg
```

```bash
lvs
```

Observed:
- Logical volume `app-data` created successfully

---

# Task 5: Format and Mount

```bash
mkfs.ext4 /dev/devops-vg/app-data
```

```bash
mkdir -p /mnt/app-data
```

```bash
mount /dev/devops-vg/app-data /mnt/app-data
```

```bash
df -h /mnt/app-data
```

Observed:
- Logical volume formatted with ext4
- Mounted successfully on `/mnt/app-data`

---

# Task 6: Extend the Volume

```bash
lvextend -L +200M /dev/devops-vg/app-data
```

```bash
resize2fs /dev/devops-vg/app-data
```

```bash
df -h /mnt/app-data
```

Observed:
- Extended logical volume size successfully
- Filesystem resized correctly

---

# What I Learned

- How LVM provides flexible storage management
- Difference between Physical Volume, Volume Group, and Logical Volume
- How to extend storage without recreating partitions
