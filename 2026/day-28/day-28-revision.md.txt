### Difference between process and service?

Process:
A running program.


### What does set -euo pipefail do?

* e → Exit on error
* u → Exit on undefined variables
* pipefail → Fail pipeline if any command fails

# Task 5: Teach It Back

## Explaining Crontab To A Beginner

Crontab is a Linux scheduler used to automate repetitive tasks.

Instead of manually running commands every day, we can schedule them to run automatically.

Examples include:

* Daily backups
* Log cleanup
* Health checks
* Automated reports

A cron entry contains:
Minute Hour Day Month Weekday Command

Example:

```bash
0 3 * * * backup.sh
```

This runs backup.sh every day at 3:00 AM.
