Day 90 – Graduation: My Complete 90DaysOfDevOps Journey 🚀

90 Days. One Journey. From Linux to AI-Powered DevOps.

Today I completed the #90DaysOfDevOps 2026 challenge by TrainWithShubham.

I started with Linux fundamentals and progressed through networking, shell scripting, Git/GitHub, Docker, CI/CD, Kubernetes, Terraform, Ansible, observability, Helm, Amazon EKS, ArgoCD/GitOps, and Agentic AI for DevOps.

The biggest lesson: DevOps is not about memorizing tools. It is about connecting them into a reliable system for building, deploying, securing, monitoring, and troubleshooting applications.

💡 My Top 5 Aha Moments

1. Linux is the foundation

Understanding Linux makes debugging containers, Kubernetes nodes, CI runners, and cloud servers much easier.

2. Kubernetes is about desired state

Desired State
     ↓
Controller
     ↓
Actual State
     ↓
Reconciliation

3. GitOps changes deployment thinking

Developer → Git → ArgoCD → Kubernetes

Git becomes the source of truth.

4. Observability is essential

Deploying an application is only half the job. You also need to know what is happening after deployment.

5. DevOps is a system, not a tool

Linux, Git, Docker, Kubernetes, Terraform, Ansible, Helm, EKS, ArgoCD, monitoring, and AI solve different parts of the same engineering problem.

❤️ Advice to Someone Starting Day 1

Don't try to learn everything at once.

Start with Linux. Understand what is happening underneath. Then learn Git, containers, CI/CD, Kubernetes, infrastructure as code, cloud, observability, GitOps, and finally AI.

Most importantly:

Build something every day.

You will break things. You will get errors. You will spend hours debugging something that turns out to be one missing character.

That's not wasted time.

That's the learning.
