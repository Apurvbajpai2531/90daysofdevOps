# 🚀 TerraWeek Challenge – Day 63 | Variables, Outputs, Data Sources & Expressions

## 📖 Overview

Today I transformed my Terraform configuration from a hardcoded setup into a **dynamic, reusable, and environment-aware Infrastructure as Code project**.

By introducing variables, outputs, locals, data sources, built-in functions, and conditional expressions, I created a Terraform configuration that can easily be reused across multiple environments without modifying the core infrastructure code.

---

## 🎯 Objectives

* Replace hardcoded values with variables
* Use multiple `.tfvars` files for different environments
* Create reusable outputs
* Fetch AWS resources dynamically using Data Sources
* Use Locals for consistent naming and tagging
* Practice Terraform functions and expressions

---
