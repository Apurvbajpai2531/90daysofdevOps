# 🚀 TerraWeek Challenge – Day 62 | Providers, Resources & Dependencies

## 📖 Overview

On Day 62 of the TerraWeek Challenge, I explored one of Terraform's most powerful concepts—**Providers, Resources, and Dependencies**.

Instead of creating standalone resources, I built a complete AWS networking infrastructure including a VPC, Public Subnet, Internet Gateway, Route Table, Security Group, and an EC2 instance. I also learned how Terraform automatically determines the order of resource creation using dependency graphs and when to use explicit dependencies with `depends_on`.

---

## 🎯 Objectives

* Understand Terraform Providers
* Learn Provider Version Constraints
* Build a complete AWS Networking Stack
* Understand Implicit & Explicit Dependencies
* Visualize Infrastructure using `terraform graph`
* Explore Terraform Lifecycle Rules
* Clean up infrastructure using Terraform Destroy

## 🎯 Key Takeaways

* Infrastructure resources are connected through dependencies.
* Terraform automatically builds dependency graphs.
* Implicit dependencies are created by resource references.
* Explicit dependencies are useful when Terraform cannot infer relationships.
* Lifecycle rules provide safer infrastructure updates.
* Infrastructure can be managed predictably using code.
