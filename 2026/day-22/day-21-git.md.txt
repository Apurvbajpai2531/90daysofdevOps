## 🔄 Understanding the Git Workflow

```text
Working Directory
        │
        ▼
 Staging Area
        │
        ▼
 Repository
```

### Working Directory

The place where project files are created and modified.

### Staging Area

Temporary area where changes are prepared before committing.

### Repository

Stores the complete history of all commits.

---

## 📖 Key Learnings

* Git tracks changes in source code efficiently.
* The staging area provides control over what gets committed.
* Commits create checkpoints in project history.
* The `.git` folder contains all repository metadata and history.
* Meaningful commit messages improve collaboration and maintainability.
